# 단가표 만들기 (동방파스텍)

주소: https://useran-coder.github.io/price/

- 이 저장소의 `index.html` 은 매출 분석 도구(https://useran-coder.github.io/sales/)의 최신 파일을 불러와 **단가표 만들기 전용 화면**으로 엽니다.
- 매출 분석 도구와 같은 로그인·같은 서버 동기화를 쓰므로, 여기서 고친 단가표(작성 중인 표·저장된 단가표·세트)는 매출 분석 도구 «단가표만들기»에도 그대로 반영됩니다.
- 단가표 기능을 고치면 매출 분석 도구(sales 저장소)에 올리면 되고, 이 화면은 자동으로 같은 버전이 됩니다.
